# Amrit Tiwari 

Personal portfolio and interactive dashboard built with React, TypeScript, Vite, and Tailwind CSS.

## 🚀 Features

- **Neumorphic & Modern Design**: Clean dashboard layout with light and dark mode support.
- **Hardware & Engineering Showcase**: Highlights projects like the REFORGE FPGA + ESP32 board and SYNAPSE-32 RISC-V CPU.
- **Interactive Music Player**: Audio player widget with file upload, seek, skip, loop, and playback controls.
- **Responsive Layout**: Adapts smoothly across desktop, tablet, and mobile displays.

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/) + [Vite](https://vite.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/) + Custom SVGs

## 📦 Getting Started

### Installation

```bash
npm install
```

### Development Server

```bash
npm run dev
```

### Production Build

```bash
npm run build
```

### Preview Build

```bash
npm run preview
```
